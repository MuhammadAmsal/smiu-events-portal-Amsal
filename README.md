## Page responsibilities (2-member split)

- **Member 1:** Repository setup, shared navbar/footer, `index.html`, `events.html`, and initial README.
- **Member 2:** `event-details.html`, `societies.html`, `register.html`, `contact.html`, and final responsive testing.
- **Shared:** `css/style.css`, code review, resolving merge conflicts, and final integration.

Both members should contribute meaningful changes across the project and review each other's work. Adjust this split if your actual work history differs.

## Pages included

1. `index.html` — home hero, 3-slide carousel, 3 upcoming event cards, Why Join features.
2. `events.html` — 8 event cards and a striped/hoverable schedule table.
3. `event-details.html` — event banner and details, accordion, Register Now modal.
4. `societies.html` — 6 society cards and an admissions alert.
5. `register.html` — responsive registration form with required controls.
6. `contact.html` — contact form, office information, map placeholder, and team cards.

## How to run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension and choose **Open with Live Server**.
4. An internet connection is needed for the Bootstrap, Bootstrap Icons, and Unsplash CDN/image links.

No build process or package installation is required.

## Responsive testing

Use browser DevTools device emulation and check the layout at:
- Phone: **360px**
- Tablet: **768px**
- Desktop: **1200px**

Verify the mobile navbar toggler, card grids, form layout, carousel controls, accordion, and modal at these widths.
